# RemTexNik — сайт сервісного центру

Сайт сервісу комп’ютерної техніки в Дніпрі. Українська мова, адаптивна верстка, Node.js 22+.

## Локальний запуск

```bash
npm start
```
Відкрити http://localhost:3000 . Перевірка сервера: `/health`.

## Розгортання на Render

- New → Web Service → репозиторій `Nik8722/Remtexnik-site`.
- Runtime: Node. Build command можна залишити порожньою або `npm install`.
- Start command: `npm start`.
- Node.js: 22 або новіше. Сервер слухає `process.env.PORT`.
- Переконайтесь, що сервіс успішно розгорнувся й `/health` повертає `{"ok":true}`.

## Telegram заявки

Форми «Замовити дзвінок» і «Задати питання» надсилають повідомлення через Telegram Bot API. Потрібні змінні середовища Render:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Не додавайте токен до GitHub. Після налаштування перевірте обидві форми на робочому сайті.

## Відгуки

За умовчанням сайт може читати схвалені відгуки з `reviews.json`, але не приймає нові відгуки без постійного сховища. Щоб дозволити надсилання:
- підключіть persistent disk;
- встановіть `REVIEWS_FILE` на шлях JSON-файлу на цьому диску, попередньо створіть файл з `[]`;
- реалізуйте адміністративне схвалення (`status: "approved"`): нові відгуки мають `status: "pending"`.

На тимчасовій файловій системі Render записи можуть бути втрачені після redeploy. Не ввімкніть цю функцію без постійного сховища.

## Підключення домену

У Render → Settings → Custom Domains додайте власний домен. DNS-записи встановлюйте тільки за інструкціями саме вашого Render-сервісу й реєстратора. Зачекайте підтвердження DNS та випуску HTTPS-сертифіката. Перевірте домен з `www` та без, головну й усі сторінки послуг, телефонні посилання й відправлення Telegram-заявок.

## Чеклист перед запуском

- Звірити всі ціни з затвердженим прайсом власника.
- Звірити перелік послуг (включно з телевізорами та приставками).
- Пройти сайт у Chrome на телефоні та на ПК.
- Перевірити контактні форми і наявність Telegram-сповіщень.
- Визначити, чи потрібна окрема політика конфіденційності для форми з телефоном.
- Перевірити запуск на платному домені та HTTPS.

Блог видалений; колишній URL `/blog.html` перенаправляється на головну.
